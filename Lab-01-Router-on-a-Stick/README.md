# Router-on-a-Stick

## Overview

A Cisco Packet Tracer lab demonstrating inter-VLAN routing using
Router-on-a-Stick.

### Topology

- 1 Router
- 1 Switch
- 3 VLANs
- VLAN 10 is used on two separate floors
- VLANs 20 and 30 for other network segments

![Topology](https://github.com/zackrage99/cisco-networking-labs/blob/main/Lab-01-Router-on-a-Stick/Router-on-a-Stick-Topology.png)

### Configuration

- Created VLANs 10, 20, and 30
- Configured access and trunk ports
- Configured Router-on-a-Stick using 802.1Q subinterfaces
- Configured IP addressing and default gateways
- Tested inter-VLAN connectivity using ping

### Technologies

Cisco Packet Tracer · Cisco IOS · VLANs · 802.1Q · Inter-VLAN Routing
