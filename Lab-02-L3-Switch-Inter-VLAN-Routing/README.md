# Lab 02 – Layer 3 Switch Inter-VLAN Routing

## Overview

A Cisco Packet Tracer lab demonstrating inter-VLAN routing using a
Layer 3 switch, with a router providing Internet access.

### Topology

- 2 Layer 2 switches
- 1 Layer 3 switch
- 1 Router
- 4 VLANs
- Multiple end devices

![Topology](https://github.com/zackrage99/cisco-networking-labs/blob/main/Lab-02-L3-Switch-Inter-VLAN-Routing/L3-Switch-Inter-VLAN-Routing-Topology.png)

### Configuration

- Created and configured 4 VLANs
- Configured access and trunk ports
- Configured inter-VLAN routing using SVIs on the Layer 3 switch
- Configured a routed point-to-point link between the Layer 3 switch and router
- Configured a default route toward the router
- Configured Internet access
- Tested connectivity between VLANs and toward the Internet

### Technologies

Cisco Packet Tracer · Cisco IOS · VLANs · 802.1Q · Layer 3 Switching ·
Inter-VLAN Routing · Static Routing
