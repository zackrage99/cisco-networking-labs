# Cisco Networking Labs

This repository contains my Cisco Packet Tracer labs created as part of my
networking and cybersecurity learning journey.

I am currently studying computer networking and CCNA concepts while building
practical experience with Cisco networking technologies.

## Labs

### Lab 01 – VLANs, Trunking & Inter-VLAN Routing

Topics covered:
- VLAN configuration
- Access ports
- Trunk ports
- Inter-VLAN routing
- IP addressing
- Subnetting
- Connectivity testing

### Lab 02 – VLSM & Routing

Topics covered:
- VLSM subnetting
- IP address planning
- LAN addressing
- Point-to-point router connections
- Static routing
- Connectivity testing

## Tools

- Cisco IOS
